#  Flappy Bird Deep Q-Learning (DQN)

A Reinforcement Learning project that trains an AI agent to play **Flappy Bird** using the **Deep Q-Network (DQN)** algorithm with **PyTorch**.

## Features
- Deep Q-Network (DQN)
- Experience Replay
- Target Network
- Epsilon-Greedy Exploration
- PyTorch & Gymnasium

## Tech Stack
- Python
- PyTorch
- Gymnasium
- NumPy
- PyYAML

## ▶ Train

python agent.py default --train


##  Test
python agent.py default


##  Project Files

- `agent.py` – Main training/testing script
- `dqn.py` – Deep Q-Network model
- `experience_replay.py` – Replay memory implementation
- `game_flappy_bird.py` – Game environment
- `parameters.yaml` – Hyperparameters
